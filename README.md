# 🛒 E-Commerce Web Application

An end-to-end E-commerce web application built using **HTML**, **CSS**, **JavaScript**, **Java**, and **SQL**. This project demonstrates a complete online shopping platform with features like user authentication, product browsing, cart management, and order processing.

## 💡 Features

- User registration and login (authentication)
- Browse products by categories
- Add/remove products to/from cart
- Checkout with order confirmation
- Admin panel to manage products and orders
- Responsive UI for mobile and desktop

## 🧰 Tech Stack

| Technology    | Purpose                              |
|---------------|--------------------------------------|
| HTML & CSS    | Frontend structure and styling       |
| JavaScript    | Dynamic client-side interactions     |
| Java (Servlets/JSP) | Backend logic and server-side processing |
| SQL (MySQL)   | Database for storing users, products, orders |
